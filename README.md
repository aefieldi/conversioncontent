# Conversion Content

Setup page and source files for the Conversion Content Claude Project: share a video idea, a brain dump or a transcript, get the videos in it with hooks, beats, captions and a YouTube plan.

- `hook-library.md`: all 630 hooks, sorted into 12 sections by what the video is about. Add this file to the Claude Project from GitHub so edits here flow through.
- `coach-instructions.md`: paste into the Project's instructions.

Live at https://aefieldi.github.io/conversioncontent/
